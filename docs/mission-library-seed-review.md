# Chambana mission review — 25 revised drafts

Revised October 28, 2026. The owner approved releasing the current 25 missions on November 4, 2026. This sheet preserves the original starter copy; the shared admin library is authoritative for later edits and publication status. There are five missions in each category, all in Urbana or Champaign.

**Photo or video proof is required for every mission.** No written reflection or review is required. Get agreement from anyone featured in a photo or video. These are mission requirements in the draft catalog; media upload and completion verification are not yet implemented.

Activities are original proposals, not venue-sponsored events. Check current opening hours, menu availability, and posted closures. Outdoor activities use open public areas; Meadowbrook closes at sunset. The linked official sources were checked on October 28, 2026. Durations and rewards are proposed product settings.

**Required video: show all 12 pushups.**
